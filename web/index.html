MediSignal API

A research portfolio prototype that turns structured synthetic FHIR R4 observations into transparent, explainable demo signals through a deployable REST API.

Data flow

FHIR R4 Bundle ↓ Validation ↓ Feature extraction ↓ Explainable demo rules ↓ JSON signal response ↓ REST API / Swagger

Scope

This project demonstrates interoperability-oriented data handling and API implementation. The included thresholds are educational examples, not validated clinical guidelines, risk predictions, diagnosis, treatment advice, or a medical device.
